Sie haben das Quiz bestanden – herzlichen Glückwunsch. Hugo Learn generiert sofort ein **personalisiertes Zertifikat** als PDF. Diese Anleitung zeigt, wie Sie es herunterladen und wofür Sie es nutzen können.

## Schritt 1: Zertifikat aufrufen

Direkt nach dem bestandenen Quiz sehen Sie eine Erfolgsseite mit:

- Ihrem **Namen**
- Dem **Modulnamen**
- Ihrem **Quiz-Score**
- Einem Vorschau-Bild des Zertifikats
- Einem Button **„Zertifikat herunterladen"**

Klicken Sie auf den Button. Das PDF wird in Ihren Standard-Download-Ordner gespeichert.

## Schritt 2: Zertifikat öffnen

Das PDF zeigt:

- Ihren Namen (vollständig)
- Den Modulnamen (z. B. „Datenschutz-Grundlagen")
- Das Datum des Abschlusses
- Ihren erreichten Quiz-Score
- Eine eindeutige Zertifikats-ID
- Einen QR-Code zur Online-Verifizierung
- Das Logo Ihres Arbeitgebers (wenn er es hochgeladen hat)
- Die Unterschrift des DSB Ihrer Firma (wenn aktiviert)

![Zertifikats-Bereich in Hugo Learn](/screenshots/dsb-nis2-gf-schulung.png)

## Schritt 3: Was tun mit dem Zertifikat?

### Option 1: Persönliche Akte

Speichern Sie das Zertifikat in einem **eigenen Ordner** auf Ihrem Computer. So haben Sie eine Sammlung Ihrer abgeschlossenen Schulungen – auch unabhängig vom Arbeitgeber.

### Option 2: Lebenslauf

Wenn Sie sich bewerben, können Sie das Zertifikat als **Anhang** im Bewerbungsdossier mitschicken. Es zeigt: „Ich nehme Datenschutz ernst." Bei Stellen mit Compliance-Bezug (Personal, Buchhaltung, IT) ist das ein Plus.

### Option 3: Personalakte

Manche Arbeitgeber wollen das Zertifikat in der Personalakte haben. In dem Fall reicht oft, das PDF an die Personalabteilung zu schicken oder es in einem Mitarbeiter-Portal hochzuladen.

## QR-Code-Verifizierung

Auf jedem Zertifikat ist ein QR-Code. Wer ihn scannt (z. B. mit der Kamera-App eines Smartphones), landet auf einer **Verifizierungsseite**:

```
docs.fraghugo.de/verify/[ZERTIFIKATS-ID]
```

Dort kann jeder prüfen:
- Existiert das Zertifikat wirklich?
- Wer hat es bestanden?
- Wann wurde es ausgestellt?
- Welches Modul wurde absolviert?
- Gilt es noch?

So kann ein neuer Arbeitgeber oder Auditor leicht prüfen, ob das Zertifikat echt ist.

## Schritt 4: Zertifikat erneut herunterladen

Wenn Sie das PDF verloren haben, ist das kein Problem. Loggen Sie sich erneut über den ursprünglichen Magic Link ein und gehen Sie auf **„Meine Schulungen"**. Dort sehen Sie alle abgeschlossenen Module mit einem Download-Button.

> 💡 **Tipp:** Markieren Sie sich die Schulungs-Mail von Hugo Learn als „wichtig" oder verschieben Sie sie in einen eigenen Ordner. Dann finden Sie den Link auch Monate später noch.

## Wie lange ist ein Zertifikat gültig?

Ein Zertifikat ist **technisch unbegrenzt** gültig – das PDF läuft nie ab. Aber:

- Manche Arbeitgeber verlangen **jährlich neue Zertifikate** (also: jährlich neue Schulung)
- Bei NIS2- oder ISO-Audits wird oft das **aktuellste Zertifikat** verlangt (nicht älter als 12 Monate)
- Im Lebenslauf wirken **frische Zertifikate** glaubhafter

Praxis: Behalten Sie alte Zertifikate, aber machen Sie jährlich eine neue Schulung. Hugo Learn erinnert Sie automatisch.

## Mehrere Zertifikate sammeln

Wenn Sie alle drei Pflicht-Module absolvieren, haben Sie drei Zertifikate:

1. Datenschutz-Grundlagen
2. Sicherheit am Arbeitsplatz
3. Datenpanne melden

Wenn Ihr Arbeitgeber zusätzlich monatliche Awareness-Lektionen aktiviert hat, kommen pro Jahr noch bis zu 12 Mini-Zertifikate hinzu.

In Ihrem persönlichen Bereich finden Sie eine **Übersicht aller Zertifikate** mit Download-Buttons.

## Branding und Sprache

- **Deutsch oder Englisch** – wählen Sie beim Schulungs-Start
- **Logo Ihres Arbeitgebers** – falls hochgeladen, erscheint es oben
- **Unterschrift des DSB** – falls eingerichtet, erscheint sie unten
- **Eigene Texte** – manche Arbeitgeber passen die Zertifikats-Texte an

## FAQ

**„Kann ich das Zertifikat fälschen?"**
Theoretisch ja (PDF lässt sich bearbeiten) – praktisch nein, denn der QR-Code verweist auf die echte Verifizierungsseite. Wer das prüft, sieht sofort, ob das Zertifikat echt ist.

**„Wer hat Zugriff auf mein Zertifikat?"**
- Sie selbst (Download)
- Ihr Arbeitgeber (sieht „bestanden"-Status, kann das Zertifikat selbst herunterladen)
- Wer den QR-Code scannt und damit die Verifizierungsseite öffnet

**„Was, wenn ich den Job wechsle?"**
Das Zertifikat **bleibt gültig**. Es ist auf Ihren Namen ausgestellt, nicht auf den Arbeitgeber. Sie können es im neuen Job mitnehmen.

**„Bekomme ich auch ein Zertifikat für die Awareness-Lektionen?"**
Ja – ein „Mini-Zertifikat" pro Lektion. Manche Arbeitgeber bündeln die zu einem Jahres-Zertifikat („12 Awareness-Lektionen 2026").
